# Writing and Review refinements

This update follows the three requests made after the initial enhancement release. The preceding version remains in Git at `b839a48`; the original master branch and external backups are unchanged.

- **New-file titles:** new files focus the title and select the entire `Untitled` name. Typing replaces it. Tab, collection/folder, and Quick actions creation paths share this behavior, including when starting from Reading mode. Existing titles retain normal cursor-based editing, and saves retain the new name.
- **Selection actions:** dictionary, study card, and link actions sit eight pixels above the visible selected passage. They follow scrolling and viewport changes, wrap on narrow screens, and move below only when there is insufficient space above. Selections in reading mode are tracked inside the toolbar so showing it does not rerender the selected Markdown. The source text stays intact when opening an action.
- **Review:** reduced spacing, compact statistics and cards, a prominent Study groups section, and explicit Create/Edit group dialogs. Existing groups and learning records are preserved.
- **Linked study groups:** optional `settings.cardGroups[].containerId` connects a group to a collection or folder by stable ID. Unassigned cards from notes, dictionary scopes, citation origins, or custom subject scopes under that location are included automatically, including descendants. An explicit `ReviewItem.groupId` assignment takes priority. All cards remains the complete queue; Ungrouped excludes cards already included through a linked group. Unlinking or deleting a group never deletes cards or learning history. Trashed or missing source locations are excluded from automatic membership. Moving a note updates its automatic grouping; renaming/moving a linked folder preserves the connection. Backup import remaps linked container IDs and avoids overwriting differently linked groups with the same name.
- **Dropdowns:** shared closed controls use theme colors and clear focus states. Supported browsers also render themed popup surfaces, rounded options, selected checkmarks, and constrained scrolling using [customizable native selects](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Forms/Customizable_select). Other browsers retain their native option picker with the styled closed control. Existing native form semantics and keyboard behavior remain in use.

No new SQL migration is required: group links extend the existing private settings JSON and are persisted through the current workspace API. No local notes, browser databases, cloud records, or attachment bytes were cleared. External Supabase/AI configuration status is unchanged.

Focused browser evidence covers automatic title replacement/persistence through three creation paths, toolbar-to-selection geometry before and after scrolling, narrow-screen reading selections, opening a styled dropdown with actual options, linked group creation/edit/reload/delete, and Review accessibility. Domain tests cover membership priority, note moves, folder renames, deletion preservation, and backup ID mapping. The full production suite is run before delivery; results are recorded in `docs/evidence/review-writing-verification.json`.
