# Keyboard guide

Mod means Ctrl on Windows/Linux and Command on macOS.

- Mod+P: command palette.
- Mod+O: note switcher.
- Mod+Shift+D: dictionary palette.
- Mod+Shift+F: workspace search.
- Mod+Shift+Q: Quick Note.
- Mod+Shift+Z: Zen toggle; this overlaps redo in some environments, so remap it when needed.
- Mod+B / Mod+I: bold / italic.
- Mod+Z and platform redo: CodeMirror undo/redo when not overridden by an app mapping.
- Mod+F: in-note search while editing.
- Tree arrows move through visible rows; Left/Right collapse/expand. Enter opens/focuses; F2 renames; Delete trashes a note. Remaining actions have keyboard-accessible menus.
- Escape closes dialogs and restores focus. Palettes support arrows and Enter.

Settings → Shortcuts accepts mappings and reports duplicate/browser conflicts. The OS/browser can reserve a combination before the app receives it; remap that command and use its visible button meanwhile. Chromium was tested. Safari, Firefox, physical IME input, and a physical screen reader are not verified.
