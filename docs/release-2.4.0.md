# Studyspace 2.4.0 — Weekly checkups and scratchpads

## What's new

- Weekly checkups: choose a template and move through a guided weekly planning session covering tasks, calendar plans, meals, finances, wellbeing, reflection, and goals.
- Build custom checkup templates, save and resume drafts, compare past weeks, and track consistency and completed commitments.
- Back and Next stay in place while each checkup section scrolls. Finance inputs have matching alignment and sizing.
- A simpler sidebar with Collections, Quick notes, Journal, Weekly checkups, and Library. Library includes Discover, Shared with me, Bookmarks, and Card Review. Global Search sits above the main tabs.
- Quick Notes scratchpads: start a blank drawing with the pen ready, save it automatically, reopen it, or move it into a collection. Includes the existing drawing tools, shapes, text, undo/redo, and PNG export.

## Download and installation

Download **Studyspace-Setup-2.4.0-x64.exe** from this release. Close Studyspace before running the installer. The application identity and existing desktop data location are unchanged. Browser and desktop workspaces use separate storage.

The Windows x64 installer is unsigned; Windows may display an unknown-publisher warning. `SHA256SUMS.txt` includes checksums for the installer and update assets. The matching blockmap and `latest.yml` support the existing desktop updater.

This release updates the desktop application and source code. It does not deploy hosted services or database migrations.
